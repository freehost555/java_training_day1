01 — JAVA DAY 1

Introduction to Java

Understand what Java is, where it is used and why it is important.

What is Java?

  • Java is a high-level, class-based, object-oriented programming language.
  • Java was originally developed at Sun Microsystems.
  • Java source code is compiled into bytecode.
  • Bytecode is executed by the Java Virtual Machine (JVM).
  • Java follows the principle: Write Once, Run Anywhere (WORA).

Applications of Java

  • Web Applications
  • Backend Development
  • Enterprise Applications
  • Android Applications
  • Desktop Applications
  • Banking & Financial Systems
  • Cloud Applications
  • Big Data Technologies

Features of Java

  • Simple
  • Object-Oriented
  • Platform Independent
  • Secure
  • Robust
  • Portable
  • Multithreaded
  • High Performance
  • Distributed
  • Automatic Memory Management

03 — JAVA DAY 1

JDK, JRE & JVM

Three terms students must understand for interviews.

JVM — Java Virtual Machine

Executes Java bytecode on the target machine.

.class file → JVM → Execution

JRE — Java Runtime Environment

Provides the environment required to run Java applications.

JRE → JVM + Java Libraries

JDK — Java Development Kit

Provides tools required to develop Java applications.

JDK → JRE + Development Tools

JDK → Develop + Run   |   JRE → Run   |   JVM → Execute

Interview Question

Q: Is Java platform independent?

Java source code is compiled into platform-independent bytecode. A JVM specific to each operating system executes that bytecode.

Java Program Structure

Understand the purpose of every important part of the first Java program.

First Java Program

class Main {

    public static void main(String[] args) {

        System.out.println("Hello Java");

    }
}

class

Defines a class.

Main

Name of the class.

main()

Starting point of a Java application.

public

Makes the method accessible to the JVM.

static

Allows the JVM to call main() without creating an object.

void

The method does not return a value.

String[] args

Stores command-line arguments.

System.out.println()

Prints output to the console.

Variables & Data Types

Learn how Java stores different kinds of values.

Variables

A variable is a named memory location used to store a value.

int age = 20;

Variable Naming Rules

  • Can contain letters, digits, _ and $.
  • Cannot start with a digit.
  • Cannot use Java keywords.
  • Java is case-sensitive.
  • Use meaningful names.

Examples

int age = 20;
double salary = 25000.50;
char grade = 'A';

06 — JAVA DAY 1

Type Casting

Convert one data type into another.

Widening Casting

Smaller type → larger compatible type. Usually happens automatically.

int a = 10;
double b = a;
int → double

Narrowing Casting

Larger type → smaller type. Requires explicit casting.

double a = 10.5;
int b = (int) a;
double → int

Note: The fractional part is discarded.

07 — JAVA DAY 1

Operators

Use operators to calculate, compare, combine and modify values.

Arithmetic Operators

+-*/%
int a = 10;
int b = 3;

a + b  // 13
a - b  // 7
a * b  // 30
a / b  // 3
a % b  // 1

Note: Integer division discards the decimal: 10 / 3 = 3.

Relational Operators

><>=<===!=

The result is always true or false.

Logical Operators

&&||!
  • && — AND: both conditions must be true.
  • || — OR: at least one condition must be true.
  • ! — NOT: reverses the result.

Assignment Operators

=+=-=*=/=%=
int x = 10;
x += 5;

// Same as:
x = x + 5;

Increment & Decrement

++--

Pre-increment: ++x — increase first, then use.

Post-increment: x++ — use first, then increase.

int x = 5;
int y = x++;

System.out.println(x); // 6
System.out.println(y); // 5

Ternary Operator

condition ? value1 : value2;
int age = 20;
String result =
    age >= 18 ? "Adult" : "Minor";

Bitwise Operators

&|^~<<>>

Bitwise operators work at the bit level. For Day 1, focus on the basic idea and simple examples.

09 — JAVA DAY 1

Decision Making

Control which block of code executes based on conditions.

if

if (condition) {
    // code
}

if-else

if (condition) {
    // true
} else {
    // false
}
if (number % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}

else-if

if (marks >= 90) {
    System.out.println("A");
} else if (marks >= 75) {
    System.out.println("B");
} else if (marks >= 60) {
    System.out.println("C");
} else {
    System.out.println("D");
}

Nested if

An if statement inside another if.

if (age >= 18) {
    if (hasLicense) {
        System.out.println("Can drive");
    }
}

switch

Used when comparing one expression against multiple fixed values.

switch (day) {

    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    default:
        System.out.println("Invalid");
}

case

Defines a matching option.

break

Stops switch execution.

default

Runs when no case matches.

Placement Tip: If break is omitted, execution can continue into following cases until a break or the end of the switch (fall-through behavior).

10 — JAVA DAY 1

Loops

Repeat a block of code while a condition is satisfied.

for Loop

Best when the number of iterations is known.

for (initialization; condition; update) {
    // code
}
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

while Loop

The condition is checked before each iteration.

int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}

do-while Loop

The body executes at least once.

int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);

while vs do-while

while

Condition first → body may execute 0 times.

do-while

Body first → executes at least once.

break

Immediately terminates the loop or switch.

for (int i = 1; i <= 10; i++) {

    if (i == 5) {
        break;
    }

    System.out.println(i);
}

Output: 1 2 3 4

continue

Skips the current iteration and moves to the next iteration.

for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}

Output: 1 2 4 5

Nested Loops

A loop inside another loop.

for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {
        System.out.print("* ");
    }

    System.out.println();
}
